++ 전위 후위 연산자에 대해서 설명해 보자.

전위 증가 연산자(++a):
int a = 5;	
int b = ++a; // a = a + 1, b = a;	
System.out.println(a); 
System.out.println(b); //6, 6

후위 증가 연산자(a++):
int a = 5;	
int b = a++; // b = a, a = a + 1;	
System.out.println(a);  
System.out.println(b); //6 5

형변환이란?

프로그램에서 특정 자료형을 다른 자료형으로 변환하는것을 의미

캐스팅 연산자란?
변경전 데이터를 변경후 자료형으로 강제 형변환 자동형변환 시키는것 

자동형변환과 명시적 형변환을 설명하시오.
자동형변환은 프로그램 내에서 자동으로 형변환되고
 강제 형변환은 개발자가 원하는 형태로 강제로 형변환하는 것

명시적 형변환시 주의할 점은 무엇인가?
강제 형변환된 데이터는 화면에 출력해 보면 손실이 발생 할 수 있으니 주의 해서 사용해야 한다

자료형변환 고려사항 6가지를 기술해서 물음표를 체우자.
정수 실수 자료형의 저장 범위크기 순으로 기술하시오.
int이하 자료형은 int형으로 자동형 변환 된다.
 byte + byte는 int형이 된다.
int는 long로 자동 형변환 된다. 
long은 float로 자동형 변환된다. 
float은 double로 자동 형변환 된다. 
boolean자료형은 몇몇 언어에서는 true면 1, false면 0으로 자동 형변환 되기도 하지만 자바에서는 boolean형의 자동 형변환 및 강제 형변환이 불가능 하다.
캐스팅 연산자는 산술연산자보다 우선순위가 높다  .


(int)11.1+11.1과 (int)(11.1+11.1)의 연산결과는 무엇이고 이유를 설명하시오.
11+11.1 = 22.1    인트와 더블은 더블이 높기에 더블로   인트와 인트는 인트로   22
다른 두가지 자료형이 연산되는 방법을 기술한것이다 물음표를 채우자.

같은 자료형을 연산한 결과는 같은 자료형이 나온다.
연산시 기본적으로 둘 중 더 높은 자료형으로 자동형 변환 된다.
자동 형변환을 통해 연산 결과를  같은 자료형으로 만들 수 없다면 에러가 난다.
boolean 자료형은  문자열 자료형을 제외하고는 연산할 수 없다.
int 자료형보다 작은 정수 자료형과 문자 자료형은 연산 결과 int형이된다. 
long + (byte,short,char,int)==long 형 자료형이 된다.
long + float == float, long + double == double형 자료형이 된다.
double + (문자열과 boolean를 제외한 모든 자료형)의 결과는 double이 된다.
float + (문자열과 boolean,double 를 제외한 모든 자료형)의 결과는 float이 된다.
문자열 + 모든 자료형은 결과는 문자열이다.
문자열 연산은 +연산만 가능하다.
문자열은 다른 자료형으로 변환하기 위해서 캐스팅 연산자를 사용할수 없다.
문자열 “11” 를 int형변환 할때사용하는 메소드는 parse
문자열를 double형변환 할때사용하는 메소드는? parse
문자열를 boolean형변환 할때사용하는 메소드는? parse
다양한 자료형을 문자열로 변경 하려면 “”+자료형 하면 된다.
